## 功能概述

在接地点对比分析系统中新增50英尺无线电高度点的地图标记功能，帮助飞行员和分析师更好地了解着陆过程中的垂直剖面。

## 背景说明

在飞行训练和着陆质量分析中，50英尺高度是一个关键的参考点：
- **法规要求**：许多国家要求飞行员在50英尺高度时建立稳定的着陆形态
- **安全指标**：50英尺到接地点的下降率和姿态是评估着陆质量的重要指标
- **训练价值**：通过分析50英尺点的位置，可以评估飞行员对下滑道的控制能力

现有系统只能显示接地点，无法看到50英尺高度时的位置。本功能通过分析QAR数据中的无线电高度（RALTC）信息，计算出50英尺高度对应的精确经纬度，并在地图上标记出来。

## 技术实现

### 1. 数据源

- **RALTC列**：无线电高度表数据（单位：英尺），记录飞机距离地面的实时高度
- **LONPC列**：经度数据
- **LATPC列**：纬度数据
- **数据采样率**：约1Hz（每秒1个数据点）

### 2. 核心算法：线性插值

由于QAR数据是离散采样，很少会有精确的50.0英尺数据点。因此需要使用线性插值计算50英尺对应的位置。

#### 插值公式

```
P = P1 + (P2 - P1) × (H - H1) / (H2 - H1)
```

其中：
- **P, P1, P2**：分别为插值点、前点、后点的经纬度
- **H, H1, H2**：分别为插值点（50英尺）、前点、后点的高度

#### 计算步骤

1. 在接地点前最多600行数据（约60秒）中搜索
2. 过滤无效数据：NaN值、<10英尺或>200英尺的异常值
3. 找到最接近50英尺的点
4. 如果误差<0.1英尺，直接使用该点
5. 否则，找高于50和低于50的两个点进行线性插值

#### 插值示例

假设数据中有两个点：
- 点A：lat=31.1500, lon=121.4600, height=52.3 ft
- 点B：lat=31.1498, lon=121.4602, height=48.7 ft

计算50英尺点的位置：
```
ratio = (50 - 52.3) / (48.7 - 52.3) = -2.3 / -3.6 = 0.639
lat_50 = 31.1500 + (31.1498 - 31.1500) × 0.639 = 31.1499
lon_50 = 121.4600 + (121.4602 - 121.4600) × 0.639 = 121.4601
```

### 3. 核心方法说明

#### `detect_50ft_point(df, touchdown_idx)`

检测50英尺高度点。

**输入参数**：
- `df`: 飞行数据DataFrame
- `touchdown_idx`: 接地点的索引

**返回值**：
- `(point_50ft, message)`: 50英尺点信息字典和状态消息

**关键逻辑**：
1. 在接地点前搜索数据
2. 清洗和验证数据
3. 找到适合插值的点对
4. 调用插值方法计算

#### `_interpolate_50ft_point(before_point, after_point, target_height, ...)`

使用线性插值计算50英尺点的经纬度。

**输入参数**：
- `before_point`: 高度>50的数据点
- `after_point`: 高度<50的数据点
- `target_height`: 目标高度（50）
- `lat_col, lon_col, raltc_col`: 列名

**返回值**：
- 包含插值后经纬度的字典

#### `_calculate_dual_point_view(lat1, lon1, lat2, lon2)`

计算同时显示两个点的地图视图参数。

**功能**：
- 计算两点的中心坐标作为地图中心
- 根据两点距离估算合适的缩放级别
- 确保两个点都能在地图中显示

### 5. 地图显示增强

- **接地点**：红色圆圈 (#FF4136)
- **50英尺点**：橙色菱形 (#FFA500)
- **自动缩放**：根据两点距离自动调整地图缩放级别

## 使用说明

### 单文件分析

1. 在接地点对比分析页面，上传包含RALTC列的CSV文件
2. 系统自动检测接地点和50英尺点
3. 地图上会同时显示两个点：
   - 红色圆圈：接地点
   - 橙色菱形：50英尺点
4. 信息面板显示两个点的详细坐标
5. 如果50英尺点是通过插值计算的，会标注"插值: 是"

### 批量导出

批量导出功能已更新，导出的静态图片会包含50英尺点标记和坐标信息。

## 边界情况处理

| 场景 | 处理策略 |
|------|----------|
| CSV中无RALTC列 | 显示警告："缺少无线电高度列"，不显示50英尺点 |
| RALTC列全为NaN | 显示警告："未找到有效高度数据"，不显示50英尺点 |
| 接地点前无数据 | 返回None，不显示50英尺点 |
| 所有数据<50英尺 | 使用最接近50的点，添加警告 |
| 所有数据>50英尺 | 使用最接近50的点，添加警告 |
| 经纬度数据缺失 | 跳过该行，继续寻找 |
| 插值计算失败 | 降级为最近点方法 |

## 测试验证

### 单元测试用例

1. **精确匹配测试**
   - 数据：包含50.0英尺的精确数据点
   - 预期：直接使用该点，不插值

2. **正常插值测试**
   - 数据：50英尺在52.3和48.7之间
   - 预期：正确计算插值点

3. **边界下限测试**
   - 数据：所有数据点都<50英尺
   - 预期：使用最接近的点，显示警告

4. **边界上限测试**
   - 数据：所有数据点都>50英尺
   - 预期：使用最接近的点，显示警告

5. **空数据测试**

## 性能影响

- **计算复杂度**：O(n)，n为接地点前的数据行数（最多600行）
- **内存增加**：可忽略不计（仅增加一个字典对象）
- **地图渲染**：增加1个Scattermapbox trace，对Plotly性能影响极小
