# 开发约定

## 日期语义（#287 定稿）

凡「今天 / 每日 / 当天」语义的日期，**一律用上海本地日**：

```python
from django.utils.timezone import localdate
today = localdate()          # ✅ 上海本地日（settings.TIME_ZONE = Asia/Shanghai）
```

**禁止**以下写法（容器 TZ=UTC，与本地日在上海 0-8 点错开一天，会造成重复发奖/漏发类 bug）：

```python
now().date()                 # ❌ UTC 日期
timezone.now().date()        # ❌ UTC 日期
date.today()                 # ❌ 随进程 TZ 漂移（容器内 = UTC）
datetime.now().date()        # ❌ 同上且 naive
```

对比/过滤 `created_at`（DateTimeField）按日期时，`created_at__date=today` 的 `__date` 查找
按 settings 时区取日期，与 `localdate()` 同口径——两者必须配对使用。

CI 防线：`build.yml` 的日期语义检查步会对非测试代码 grep 上述禁用写法，命中即 fail
（测试代码允许，用于冻结时刻回归）。

历史案例：#197（签到凌晨可无限刷分）、#287（streak 奖励/复习赚分同款），回归测试
`CheckinTimezoneWindowTest` / `StreakRewardTimezoneWindowTest` / `ReviewPointsTimezoneWindowTest`。
