## 一、系统定位

词汇表系统是 EbbinghausAnywhere 的**词汇资源库模块**，与现有的**学习管理模块**相对独立但紧密协作：

```
┌─────────────────────────────────────────────────────────────────┐
│                    EbbinghausAnywhere                           │
├─────────────────────────────┬───────────────────────────────────┤
│      词汇表系统 (资源库)      │      学习管理模块 (用户数据)        │
│                              │                                   │
│  • VocabularyBook            │  • Item (学习记录)                │
│  • VocabularyEntry           │  • Category (分类)                │
│  • 预置词汇资源               │  • Proficiency (掌握程度)         │
│  • 全局共享                   │  • 用户私有                       │
│                              │                                   │
│  └───── 导入 ────┬───────────┘                                   │
│                 │                                               │
│          ┌──────▼──────┐                                        │
│          │ 艾宾浩斯复习 │                                        │
│          │   遗忘曲线   │                                        │
│          └─────────────┘                                        │
└─────────────────────────────────────────────────────────────────┘
```

### 核心设计理念

1. **关注点分离**：词汇资源与学习数据分离，避免混淆
2. **渐进式增强**：从静态词汇表 → AI增强例句 → 个性化学习
3. **复用优先**：最大化复用现有AI、复习、积分系统
4. **扩展性**：支持多种词汇表格式，易于添加新资源

## 二、设计原则

### 原则1：临时存储，按需导入

词汇表条目（VocabularyEntry）仅作为**临时预览数据**，用户选择后才导入为学习记录（Item）。

**优势**：
- 用户可评估词汇表是否适合自己
- 避免批量导入后不学习造成的资源浪费
- 保持学习数据的纯净性

### 原则2：AI增强，三级提示词

支持三级提示词配置，实现个性化AI服务：

```
优先级1: 词汇表级提示词 (VocabularyBook.system_prompt)
   ↓ (如果为空)
优先级2: 用户级提示词 (DeepSeekConfig.system_prompt)
   ↓ (如果不存在)
优先级3: 系统默认提示词
```

**应用场景**：
- 中考词汇表：提示词指定"初中水平，简单例句"
- 高考词汇表：提示词指定"高中水平，高考真题例句"
- 四级词汇表：提示词指定"大学水平，复杂句式"

### 原则3：格式可扩展，解析策略模式

采用**策略模式**设计解析器，支持多种词汇表格式：

```python
# 当前实现
class ShanghaiZhongkaoParser(VocabularyParser):
    """上海中考词汇格式解析器"""

# 未来扩展
class GenericExcelParser(VocabularyParser):
    """通用Excel词汇表解析器"""

class CETParser(VocabularyParser):
    """四六级词汇表解析器"""
```

### 原则4：无缝集成遗忘曲线

导入词汇表条目时，自动触发艾宾浩斯复习逻辑：

```python
Item.objects.create(
    user=user,
    item=entry.word,
    content=entry.meaning,
    proficiency=Proficiency.UNFAMILIAR,      # 初始状态：不熟悉
    inputDate=today,                         # 输入日期
    initDate=today,                          # 初始日期
    next_review_date=today,                  # 当天开始复习
    current_interval=0,                      # 初始间隔为0
)
```

## 三、核心工作流

### 工作流1：词汇资源导入流程

```
PDF文件
   ↓
PDF解析器 (识别格式)
   ↓
VocabularyBook (创建元数据)
   ↓
VocabularyEntry[] (批量创建条目)
   ↓
词汇表详情页 (用户预览)
```

### 工作流2：AI增强流程

```
用户选择单词
   ↓
点击"一键获取例句"
   ↓
确定提示词 (词汇表/用户/默认)
   ↓
调用DeepSeek API
   ↓
解析JSON响应
   ↓
更新VocabularyEntry.meaning (追加例句)
   ↓
前端显示预览
```

### 工作流3：学习导入流程

```
用户选择单词 + 目标分类
   ↓
检查重复 (防止已导入)
   ↓
批量创建Item (事务保护)
   ↓
触发遗忘曲线 (设置复习参数)
   ↓
返回导入结果
   ↓
单词进入复习队列
```

### 4.4 数据完整性规则

#### 规则1：序号唯一性
同一个词汇表内，序号（sequence_number）必须唯一。

**SQL约束**：
```sql
UNIQUE(vocabulary_book_id, sequence_number)
```

#### 规则2：级联删除
删除词汇表（VocabularyBook）时，自动删除其所有条目（VocabularyEntry）。

**外键设置**：
```python
on_delete=models.CASCADE
```

#### 规则3：导入去重
从词汇表导入时，如果用户已存在相同单词（item字段相同），则跳过该单词。

**实现**：
```python
if Item.objects.filter(user=user, item=entry.word).exists():
    continue  # 跳过已存在的单词
```

#### 规则4：软删除
使用`is_active`字段实现软删除，保留历史数据。

**查询时过滤**：
```python
VocabularyBook.objects.filter(is_active=True)
```

## 七、设计过程记录

### 7.1 需求分析

#### 初始需求
用户提出新增"词汇表"功能，要求：
1. 支持浏览预置词汇表（中考词汇、高考词汇等）
2. 多选单词功能
3. 一键导入到现有背单词系统
4. 自动触发艾宾浩斯遗忘曲线复习逻辑

#### 数据结构要求
- 中文、英文、音标（美式/英式）、词性、是否掌握

#### 样例数据
- PDF位置：`docs/词汇表/2025新版上海市中考词汇默写本.pdf`
- 格式特点：
  - 第1-51页：中文默写英文（序号 + 中文释义）
  - 第52页及以后：英文默写中文（序号 + 英文单词）
  - 两部分通过序号对应拼接

### 7.2 技术选型决策

#### 决策1：数据库设计 - 独立的词汇表系统

**选项对比**：
| 方案 | 优势 | 劣势 | 选择 |
|------|------|------|------|
| 直接创建Item | 简单直接 | 无法预览，一次性导入所有，难以评估 | ❌ |
| 临时表+正式表 | 可预览选择，按需导入 | 需要额外模型，数据转换逻辑 | ✅ |

**最终选择**：创建独立的VocabularyBook和VocabularyEntry模型

**理由**：
1. 用户可以预览词汇表内容
2. 支持选择性导入，避免不必要的单词
3. 词汇表可复用，作为共享资源
4. 保持用户学习数据的纯净性

#### 决策2：例句存储位置

**选项对比**：
| 方案 | 优势 | 劣势 | 选择 |
|------|------|------|------|
| 单独例句表 | 结构清晰 | 查询需要JOIN，与现有Item不兼容 | ❌ |
| 追加到meaning字段 | 兼容现有系统，无需修改Item模型 | 字段内容混合 | ✅ |

**最终选择**：例句追加到VocabularyEntry.meaning字段

**存储格式**：
```
n. 能力；才能
例句:
1. He has the ability to solve this problem.
   翻译: 他有解决这个问题的能力。
2. ...
```

**理由**：
1. 完全兼容现有Item.content字段格式
2. 无需修改现有数据库模型
3. 前端已有解析content显示例句的逻辑

#### 决策3：音标处理方案

**发现的问题**：
- PDF英文部分包含音标，格式如 "7. *absent /ˈæbsənt/"
- 解析时容易把音标误识别为单词

**解决方案**：
1. 正则表达式先提取序号和星号标记
2. 再提取单词（音标/之前的字母部分）
3. 单独提取音标（两个/之间的内容）

**实施结果**：
- 单词和音标正确分离
- 星号标记独立存储在is_marked字段
- 单词中不再包含星号字符

### 7.3 设计演变过程

#### 阶段1：初始设计（v1.0）

**模型定义**：
```python
class VocabularyBook(models.Model):
    name = models.CharField(max_length=200)
    description = models.TextField(blank=True)
    level = models.CharField(max_length=50, blank=True)
    word_count = models.IntegerField(default=0)

class VocabularyEntry(models.Model):
    vocabulary_book = models.ForeignKey(VocabularyBook, on_delete=models.CASCADE)
    sequence_number = models.IntegerField()
    word = models.CharField(max_length=200)
    meaning = models.TextField()
```

**问题**：缺少AI配置支持

#### 阶段2：添加AI支持（v1.1）

**新增字段**：
```python
# VocabularyBook
system_prompt = models.TextField(blank=True)

# VocabularyEntry
has_examples = models.BooleanField(default=False)
```

**理由**：
- 不同词汇表需要不同的AI提示词（中考vs高考）
- has_examples字段避免重复调用API

**解决方案**：

### 7.4 关键技术问题与解决

#### 问题1：PDF两部分的序号对齐

**现象**：
- 第1-51页：序号 + 中文释义
- 第52页+：序号 + 英文单词

**解决方案**：
1. 分别解析两部分，建立序号映射
2. 按序号合并两部分的字段
3. 丢弃无法匹配的条目

**代码结构**：
```python
def parse(self, pdf_path: str) -> List[Dict]:
    part1_data = self._parse_chinese_part(pdf.pages[:51])
    part2_data = self._parse_english_part(pdf.pages[51:])
    return self._merge_parts(part1_data, part2_data)
```

#### 问题2：正则表达式匹配失败

**现象**：部分单词无法识别

**原因**：
- 格式变化：有/无星号
- 格式变化：有/无音标

**解决方案**：分步提取
```python
# 1. 提取序号
match = re.match(r'^(\d+)\.', line)

# 2. 检测星号
is_marked = '*' in line

# 3. 提取单词（音标之前）
word_match = re.match(r'^([a-zA-Z\-,]+\s*[a-zA-Z]*)', content)
```

#### 问题3：AI提示词三级配置

**需求**：
- 词汇表级别：针对特定词汇等级
- 用户级别：个人偏好
- 系统默认：保底方案

**实现**：
```python
if book.system_prompt:
    system_prompt = book.system_prompt
elif DeepSeekConfig.objects.filter(user=request.user).exists():
    system_prompt = config.system_prompt
else:
    system_prompt = DEFAULT_PROMPT
```
